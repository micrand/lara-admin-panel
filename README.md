
# Lara Admin Panel

## Présentation

Lara Admin Panel est une application web d'administration
développée avec Laravel.

Le projet vise à fournir une base structurée, maintenable
et sécurisée pour la gestion des fonctionnalités
d'administration.

## Objectifs

- Développer une application maintenable.
- Structurer le code selon les bonnes pratiques Laravel.
- Mettre en place des tests automatisés.
- Préparer un processus de développement assisté par IA.
- Automatiser progressivement les contrôles et les déploiements.

## Stack technique

- Backend : Laravel / PHP
- Base de données : PostgreSQL
- Versionnement : Git
- IDE : Visual Studio Code
